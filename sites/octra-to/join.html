PUBLIC DEVNET / TESTER GUIDE

Your path in.
On your terms.

The devnet onboarding Circle is published. Joining a network still requires an operator-issued HTTPS login server and a private, usually single-use enrollment key. Open self-service signup is not available yet.

01 / GET THE INVITE

Start with a trusted operator.

Install the official Tailscale client for your device. The operator gives you an HTTPS login-server origin and a preauth key minted by their running control service. Ask for the network name, published OCT tariff and support contact at the same time.

Do not use an offline fixture key or a server address copied from an unverified message. The key normally works once; keep it out of screenshots and public chat.

02 / JOIN THE MESH

Use the Tailscale you know.

Replace both placeholders with the values your operator provided. This command is for macOS or Linux; Windows uses the same flags without sudo.

sudo tailscale up \
  --login-server https://YOUR-OPERATOR.example \
  --authkey YOUR-SINGLE-USE-KEY

Check the result with tailscale status. On later restarts, do not reuse the single-use key; your Tailscale installation keeps the device registration.

03 / SEE THE FREE FRONT DOOR

Orient before you pay.

The operator’s bounded portal can show this Circle site after registration, even without a paid allowance. It can explain the offer and funding path. It cannot browse arbitrary Circles, sign a transaction or carry general Internet traffic for free.

The devnet source Circle is octC9XpV4K4LJWFzc16zvaS1Rk3z8nyiqS7xwswH84Tca7E. That identifies the published site; it is not a wallet or funding address.

04 / BUY FINITE TRAFFIC

Fund locally. Review the rate.

Ask your operator for an accepted prepaid plan with its exact tariff and a funded devnet OCT wallet. Review the offered bytes and OCT cost before the local client signs. For a stock Tailscale device, the client uses your public nodekey: identity, private receipt key and a durable journal:

octravpn stock-payments \
  --plan accepted-plan.json \
  --journal /private/path/plan-journal \
  --receipt-key /private/path/receipt.key \
  --node-key nodekey:YOUR-PUBLIC-NODE-KEY

Paid forwarding starts only after the byte purchase is confirmed. The operator chooses the rate; the protocol takes no commission. You can withdraw available channel OCT, while settled byte purchases stay final.

05 / USE YOUR ROUTE

Browse and exit when admitted.

Choose the operator’s advertised exit in Tailscale. On a paid route with trusted DNS and TLS, public Circles open as regular HTTPS pages at circles.octra.to. Purchased bytes are finite: the connection pauses on exhaustion rather than extending credit.

KEEP THIS PRIVATE

Your wallet stays yours.

Never paste wallet secrets, receipt keys or enrollment credentials into a Circle page. The site is read-only. Funding and signing happen in the local client.

BEFORE YOU START

Ask for four things.

  1. HTTPS login server
  2. Private enrollment key
  3. Published tariff and plan
  4. Operator support contact

Until the operator can provide all four, you can inspect this public Circle but cannot finish joining from this page alone.
